# AccessPilot Privacy Statement

## Data Collection

**AccessPilot does not collect, store, or transmit any personal data.**

- No analytics
- No tracking
- No server calls for page content

## Local Storage

Settings are stored locally using `chrome.storage.local`:

- Confirm destructive actions (on/off)
- Remember access mode preference

This data stays on your device and is not shared.

## Page Content

- DOM reading and interaction happen entirely in your browser
- Page content is never sent to external servers
- No LLM or cloud APIs by default

## Optional Future Features

If an optional LLM feature is added later:

- It will be **off by default** and require explicit user opt-in
- A clear privacy disclosure will be shown before enabling
- Users will be informed exactly what data would be sent and where

## Open Source

The extension’s source code is available for review.
