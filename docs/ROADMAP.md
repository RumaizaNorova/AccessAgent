# AccessPilot Roadmap

## Post–Hackathon (v0.2+)

- **Macro recorder:** Record flows (login, navigate, submit) and replay them
- **Personalization:** Learn which targets a user struggles with and adapt (e.g. enlarge certain elements)
- **Desktop companion:** Optional Tauri/Electron app with native messaging for cross-app hotkeys
- **On-device model:** Small classifier for intent/ranking to improve accuracy without cloud
- **Skill packs:** Community-maintained site-specific packs (e.g. “GitHub pack”, “Amazon pack”)

## v0.1 Scope (Current)

- Command palette (Ctrl+Shift+Space)
- OPEN, SEARCH, FIND, CLICK, ACCESS MODE
- Plan–act–verify loop with step log
- Local storage for settings
- Panic / Stop control
